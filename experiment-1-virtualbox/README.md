# Experiment 1 – Install VirtualBox / VMware Workstation

## Aim

To install VirtualBox / VMware Workstation with different flavours of Linux or Windows OS.

## Procedure

1. Download and install Oracle VM VirtualBox.
2. Open VirtualBox.
3. Create or import a virtual machine.
4. Select the required guest operating system.
5. Configure the virtual machine resources.
6. Complete the installation.
7. Start the virtual machine and verify that the guest operating system boots.

## Lab Environment

- Host OS: Windows
- Virtualization software: Oracle VirtualBox
- Guest OS: Linux/Ubuntu

## Result

VirtualBox was installed and a virtual-machine environment was prepared for the subsequent cloud-computing experiments.
